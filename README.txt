The Witcher 2 — Universal Dual Subtitles v2.1 FINAL
Created by ExiZz

USER START
1. Extract this ZIP anywhere.
2. Double-click START_HERE.bat.
3. On the first launch, the launcher downloads an official Python 3.13.15
   Windows 64-bit runtime from python.org and installs it PRIVATELY inside
   this folder under "runtime". Nothing is added to the system PATH and
   no separate Python installation is required.
4. After that first launch, the tool starts locally from the included runtime.

IMPORTANT
- Internet is required only for the first launch if the private runtime is
  not already present.
- Gibbed RED Tools are already included in this package.
- The tool does not modify font files.
- For Chinese/Japanese dual subtitles, follow the built-in GUIDE and set
  the game's Text Language to the selected CJK language.
- Standard non-CJK pairs use the Primary language as the game Text Language.
- The tool keeps a clean backup before installation and can restore it.

The main application is Witcher2_Dual_Subtitles_Tool.py.


EXE BUILD
---------
Run BUILD_EXE.bat on Windows. See BUILD_GUIDE.txt.
The resulting dist folder is Python-free for the end user.
