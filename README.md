# The Witcher 2 — Universal Dual Subtitles

Source code for the final v2.2.1 release by **ExiZz**.

This repository is provided for transparency and for security review of the compiled Nexus Mods release.

## What the tool does

The application combines two The Witcher 2 `.w2strings` localization files by matching text IDs and appending the secondary-language text after ` ~ `.

It also provides automatic game detection, language-file detection, clean backups, restore functionality, and Chinese/Japanese compatibility handling described in `GUIDE.txt`.
