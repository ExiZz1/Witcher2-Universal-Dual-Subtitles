# Changelog

## v3.0

- Added automatic font support for Japanese and Traditional Chinese in both language positions, including mixed Latin and Cyrillic combinations.
- Kept Primary first and used the same game Text Language slot. Updated the Turkish compatibility path and checks for Unicode, duplicate text and exceptional records.
- Added atomic installation, journal-based Restore and rollback checks with structural resource validation.
- Introduced a centered, compact window with a scrollable operation log and a locally read game emblem.
- Packaged an autonomous Windows x64 release and documented the pinned source build.
